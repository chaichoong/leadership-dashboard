### The failure: a test that only ever ran on weekdays

```
tests/sync-invariants/ceo-brief.spec.js:141
  Expected substring: "Before 10am"
  Received string:    "Weekend — no brief expected"
```

[js/ceo-brief.js:169](js/ceo-brief.js:169) has three passing branches for "Today's brief arrived":
weekend, before 10am, and arrived. The test written for it yesterday
([ceo-brief.spec.js:176](tests/sync-invariants/ceo-brief.spec.js:176)) allowed two — `fail`, or
`Before 10am`. It shipped Thursday. Today is its first Saturday.

**The code is correct. The test is wrong.** It fails all day Saturday and all day Sunday, on any
branch, regardless of what is being pushed. That is precisely the false red CLAUDE.md warns about,
the kind that invites a `SKIP_SYNC_TESTS=1` bypass — and a bypass habit picked up this weekend is
what would let a real failure through next week.

Fixed by widening the assertion to `/Weekend|Before 10am/`. The `status === 'fail'` branch — the one
that catches the actual stub bug — is untouched, so the test still fails if a stub reads as arrived
after 10am on a weekday. Re-ran: **7/7 in that spec, 82/82 across the suite.**
