## Failures needing attention

1. **[CRITICAL] Data invariant `open-tasks-carry-no-completion-date` is failing — 143 open tasks carry a completion stamp.** Monthly throughput is overstated by 143 tasks that were never finished. Needs a bulk data correction (Kevin's approval — it is a write) plus a fix to whatever write path stamps the date without setting `Is Completed`. Finding `20260809-prod-sweep-039`.

2. **[HIGH] The invariant script under-reports its own counts.** `query()` at `scripts/check-data-invariants.py:488` fetches one page of 100 and never follows the `offset` token, so it reported 100 when the truth was 143. This is the CLAUDE.md "a hand-rolled Airtable read must paginate" anti-pattern, inside the script written to catch exactly that class of bug. Finding `20260809-prod-sweep-038`.

3. **[HIGH] The sweep is running blind on data.** `javascript_tool` is denied by the permission classifier, so authentication cannot be injected and no tab's data rendering is checked — every morning, silently. Finding `20260809-prod-sweep-041`.

4. **[MEDIUM] Unhandled promise rejection on Inbound Comms.** `Uncaught (in promise) {error: Object}` — the shape of an API error body escaping with no `.catch()`. The bare async init calls at `follow-up.html:1115-1124` and `:1238` have no handler. Finding `20260809-prod-sweep-040`.

5. **[LOW] The sweep's own tab list is stale.** The skill's fallback enumeration names "Plan Builder" (retired 1 Aug 2026) and omits "KPI Library". Live sidebar is 18 entries. Finding `20260809-prod-sweep-042`.
