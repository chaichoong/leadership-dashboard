## Notes for tuning this sweep
1. **Registry drift, handled automatically.** PAGE_REGISTRY is still 27 ids but the membership changed since the task file was written: `os-bplan` is gone (Plan Builder retired from the shell) and `kpi-library` is new. Enumerating live meant this needed no edit. The task file's hardcoded example list is now stale in two entries and could be refreshed.
2. **Data load took ~35s**, well past the 20s the task file warns about. At 25s in, `PAT` was set but all three record arrays were still 0. The poll-don't-fixed-wait rule earned its keep again today.
3. **`innerText` on a hidden panel reads `display:none` content.** The Objective & Strategy iframe appeared to be showing "Enter your Airtable Personal Access Token" and "Invalid token" while the tab was off-screen. Both elements were `display:none`; once switched to, the page showed "Live · linked to Airtable". Worth recording so a future sweep does not raise a false FAIL — verify with computed style before believing panel text read while hidden.
4. **`javascript_tool` has a hard 30s ceiling.** Loops walking 4+ tabs with 2.5s settle waits time out mid-run. The app stays healthy; only the tool call dies. Batch at most 3 tabs per call, or one when the tab is slow.
5. **`net::ERR_ABORTED` on HEAD requests in the network log is benign** — it is the sitemap health check probing all 27 pages and aborting after the status line. Every one returned 200.
