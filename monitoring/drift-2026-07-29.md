### Method note for future runs
The `Drift Monitor` task query in earlier runs filtered on `{Name}`. The Tasks table primary field
is **`Task Name`** (`fldgFjGBw6bTKJFCD`) — `{Name}` matches nothing and returns a silent zero, which
reads as "no open tasks" forever. Caught here by control-querying a record known to exist. Use
`SEARCH('Drift Monitor', {Task Name})`.
