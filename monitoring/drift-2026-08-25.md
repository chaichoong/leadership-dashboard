  auto-tighten `PATCH` cannot invent a new single-select option under `typecast:true`

**What has drifted — 3 filed:**

- `20260825-drift-monitor-355` (medium, code): the `Inbound Comms Response metric fresh` health
  check passes on any non-empty string. `Metric Score` is a `singleLineText` with no timestamp
  and the table carries no published-at field, so a score written once and never republished
  reads as fresh for ever. The SOP promises this check catches a runtime that "stopped
  publishing its score". It cannot. Presence, not absence — the inverse of the rule the zone
  was built on.
- `20260825-drift-monitor-356` (medium, code): the `Daily logs` lane flags every Built/Live
  agent with no log row today. Live read this morning: 4 agents at Built/Live, exactly ONE
  writer to the log table anywhere in the repo (`scripts/inbound-triage.py`, hardcoded to the
  triage agent's row), and one row in the table in total. Three agents will be flagged every day
  for ever through no fault of their own — a permanent warning that can never clear.
- `20260825-drift-monitor-357` (low, code/docs): the queue is filtered a second time to Kevin's
