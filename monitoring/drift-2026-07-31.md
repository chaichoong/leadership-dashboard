### NEW FAIL — the CEO Brief tab cannot tell a huddle stub from a finished brief

Yesterday's commit `5d33d4e` gave the brief a two-stage write. The 07:30 local `ceo-huddle` task
writes today's record first, carrying only One Thing, First Step and Board Flags. The 09:00 worker
then PATCHes the rest in — money light, safe-to-act, why, ignore-today, handed-off, full brief.

[js/ceo-brief.js](js/ceo-brief.js) `renderCeoBriefContent` decides whether the brief has arrived by
asking one question: *is there a record dated today?* The huddle stub **is** a record dated today, so
the tab renders it as the finished article and suppresses the "Today's brief has not arrived yet"
warning.

Reproduced in the browser against the real record now in the table, not reasoned about:

```
todayISO:                 2026-07-31
showsNotArrivedWarning:   false      <- the warning is hidden
rendersAsTodayCard:       true       <- reads as a complete brief
moneyLightBadge:          "—"        <- should be GREEN / AMBER / RED
safeToActShown:           "—"        <- should be a figure
hasWhy / hasIgnore / hasHandedOff:  false / false / false
```

So for 90 minutes every weekday the CEO Brief tab shows a hollow card with no light, no figure and
no reasoning, and nothing on screen says it is unfinished.

**The fix already exists on the other side of the same pipeline.** The worker's `gatherHuddle()`
answers the identical question with `if (getField(rec, F.ceoFullBrief)) return null; // worker
already ran today`. The read side should use the same marker. One file, `js/ceo-brief.js`, not a
shared one. Escalated as `rec8Q5NVspOHwimyb`; not auto-fixed, because UI logic is not in the
auto-fix list.

**Why it is on screen right now rather than only 07:30–09:00.** The huddle's first run was manual,
at 13:42 London on 30 Jul (`createdTime` 2026-07-30T12:42:18Z), and it dated itself 31 Jul. Today's
stub has therefore been sitting on the tab since yesterday afternoon.

**Second, smaller point, carried in the same task.** The `ceo-huddle` scheduled task has not yet
fired on its own 07:30 schedule. The 30 Jul record was created at 08:01 UTC by the worker's POST
path, which only runs when `gatherHuddle` found nothing — so the huddle had written nothing by 09:01
London that day. Its directory was created at 13:14 on 30 Jul. Today's 07:30 run is the first real
one, and tomorrow's `createdTime` will show whether it fired.
